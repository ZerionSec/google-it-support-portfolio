## 🛠️ Skills Acquired

The curriculum covered six core competency areas:

### 🌐 1. Networking & Infrastructure

- **Computer Networking** – Understanding how data moves across LANs, WANs, and the Internet.
- **TCP/IP** – Mastery of the protocol stack: Ethernet, IP addressing, routing, and transport protocols (TCP/UDP).
- **Network Troubleshooting** – Applying the OSI model systematically to isolate and resolve connectivity failures.
- **Network Administration** – Managing switches, routers, VLANs, and wireless access points.
- **General Networking** – Subnetting, ARP, DNS, DHCP, and NAT.
- **IT Infrastructure** – Designing and maintaining reliable data center and office network components.
- **Web Presence** – Understanding web hosting, DNS resolution, and HTTP/HTTPS services.

### 🔒 2. Cybersecurity & IT Security

- **Network Security** – Configuring firewalls, ACLs, and secure remote access (VPNs).
- **Information Systems Security** – Applying the CIA triad (Confidentiality, Integrity, Availability), authentication, and authorization.
- **IT Security Architecture** – Designing secure network topologies and implementing defense-in-depth strategies.

### ⚙️ 3. Systems Administration & Support

- **Systems Administration** – Managing enterprise servers, user accounts, and permissions.
- **Operating System Administration** – Hands-on configuration of both Windows and Linux environments.
- **Desktop Support** – Troubleshooting end-user hardware, software, and peripheral issues.
- **Package and Software Management** – Installing, updating, and maintaining software using package managers (APT, YUM, Chocolatey).

### 🤖 4. IT Automation (DevOps Foundation)

- **IT Automation** – Replacing manual, repetitive tasks with reliable, repeatable scripts.
- **Infrastructure as Code (IaC)** – Using automation tools to provision and configure systems consistently.

### 💻 5. Development & Collaboration Tools

- **Version Control (Git)** – Tracking code, configuration files, and documentation changes effectively.
- **Ruby** – Using a dynamic programming language for scripting and automation tasks.
- **Chef** – Writing recipes and cookbooks to automate system configuration at scale.

### 👨‍💼 6. Professional & Career Readiness

- **Interviewing Skills** – Preparing for technical interviews with structured problem-solving approaches.
